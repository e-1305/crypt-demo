# crypt-demo

The patient for [CRYPT](https://github.com/e-1305/crypt), built for Kiroween 2026.

A tiny app stitched together from deliberately outdated dependencies, so CRYPT has real rot to find and real fixes to propose.
CRYPT's agents open fix PRs here. CI runs on every PR. **Only a human merges.**

Not for production use.
